# 学生长期记忆与教师工作台

教师工作台有三个独立入口：过程轨迹、过程性评价、长期记忆。前两者以单次作答为单位；长期记忆以服务端学生账号为单位，跨项目汇总。教师试用账号单列，匿名历史演示不产生学生记忆。

## 使用流程

1. 在“过程性评价”选择学生和作答，生成评价并核对证据。
2. 进入“长期记忆”，选择该学生的一次已完成评价，点击“提取候选记忆”。也可从评价详情直接跳转。
3. 模型结合软硬评价、过程片段、引用事件摘录和现有有效记忆，提取最多四条观察。证据不足可以返回零条；界面保留局限说明。长事件仅提供标明不完整的摘录，教师可跳转原文核验。
4. 教师逐条修订、填写核验说明后确认启用，或不采用。只确认有来源、情境与帮助归因的观察。候选记忆不会注入学生助手。
5. 学生下一次协作时，助手读取相关已确认记忆，调整提示和核验方式。教师可随时修订或停用。

提取会调用当前配置的模型，费用记入发起提取的教师账号。同一评价版本重复点击复用已有结果，不重复生成；失败可以重试。按学生防止重复运行，后台任务串行执行，重启中断任务标记失败。

## 记忆内容与自演进

记忆分为能力证据、待支持环节、协作习惯、辅导策略。每条包含：适用知识点或情境、有范围的观察、学生与 AI 贡献、下次辅导建议、可观察的核验方式、来源作答/评价/复核版本、事件 ID、创建时间与教师修订历史。

历史观察和当前总结由同一组可追溯条目组成；不另生成没有证据的总画像，不从一次分数推断永久能力或人格。单次成功不等于已经迁移掌握；表达偏好不等于教学有效。

后续评价可产生新候选，模型可提出替代某条已有记忆。只有教师确认替代关系后，旧条目才标记为“已被新证据替代”；取消替代勾选则保留两条情境观察。旧内容和修订历史不删除。当前正式记忆以教师确认为准，首版没有无人审核的自动发布和模型训练。

同一作答出现新的已完成评价，或当前评价增加教师复核版本时，旧来源记忆自动显示“来源已更新”，立即退出助手检索，需要从新版本重新提取。仅追加学生交互不会抹去此前有效的历史观察。超过 90 天的记忆在界面和助手上下文标记需重新核验；这只是可配置前的保守默认时效提示，不是遗忘率预测。

## 助手接入

在 AgentRuntime 组装对话上下文前调用记忆检索，严格使用服务端登录账号的 ownerId。按当前问题词项、项目相关性、协作/策略类别与时间排序，最多四条、9 KB。首版使用轻量词项匹配，没有向量模型或知识追踪训练。数据库包含停用与历史条目，但这些不会参与检索。

记忆通过单独的历史参考消息注入，不写入全局系统提示词或持久对话状态。系统规则明确其不可信数据属性；只能调整辅导，不改变审批权限、任务约束或评分。每轮重新检索，因此停用与来源更新可在后续调用生效。实际注入的记忆 ID、版本和内容保存到现有 agent_history 中便于审计，不向学生展示教师内部评语。

过程评分器不读取学生记忆，避免旧判断影响新评分，再反过来强化旧判断。记忆检索失败时助手仍能正常工作。新证据应优先于旧观察，不能因为旧标签持续追问已经表现出理解的内容。

## 存储、接口与部署

使用独立 SQLite，默认 `data/memory/memory.sqlite`，支持 `MEMORY_DATA_DIR`，目录权限 700、数据库 600。备份时使用一致的 SQLite 备份方式，或停止服务后备份整个目录及其他作答/评价数据，不能漏掉活动 WAL。

教师接口：

- `GET /api/teacher/students/:studentId/memory`：来源、条目与任务状态。
- `POST /api/teacher/students/:studentId/memory`：`{traceId}`，从最新已完成评价提取候选。
- `POST /api/teacher/students/:studentId/memory/:memoryId`：带当前 `version` 的确认、修订、停用或不采用，拒绝并发覆盖。
- `GET /api/teacher/students/:studentId/memory/export`：导出条目、来源与历史。

所有接口要求教师角色；写操作沿用同源与 CSRF 保护。模型不能通过工具直接修改记忆。依赖不变，服务重启加载新后端，网页刷新加载界面。

## 验证边界

自动化测试覆盖候选不召回、账号隔离、重复生成、教师确认与停用、并发版本冲突、来源修订失效、新证据替代、非法引用、持久化恢复、助手参考消息和权限/CSRF。浏览器验收使用替身模型，确认导航、评价、提取、复核和证据跳转。真实模型的特征提取准确率和教学效果仍需教师用实际案例校准，不能用流程测试替代效果验证。

## 测试版：助手主动查询记忆

新增只读工具 `search_student_memory({query})`。默认关闭，配置 `AI_MEMORY_SEARCH_ENABLED=true` 并重启服务后，才会向模型提供该工具。关闭时工具不进入模型工具列表，即使模型输出同名调用，执行端也会拒绝。学生不能通过聊天或请求参数开启它。

工具账号范围由登录会话决定，参数仅接受 1–300 字的 query，拒绝指定其他账号。复用现有检索器，仅返回教师确认、来源有效、未停用的记忆，最多四条、9 KB。工具结果及引用随现有工具调用历史保留。不能创建、修订、确认或删除记忆。

此开关只控制新增的主动工具查询，既有的自动记忆参考流程保持不变。测试版尚未验证真实模型主动检索的教学效果，线上保持关闭。
